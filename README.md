Gate Monitor
============
Bring your old gate opener into the digital age.

Parts List
----------
 * Seeed XIAO ESP32-C3
 * Adafruit ADS1115 ADC breakout board
 * Pololu D36V6F3 3.3V, 600mA step-down voltage regulator
 * Adafruit 10K Precision Epoxy Thermistor
 * Mighty Mule GTO/1000 gate opener - circa 2000
